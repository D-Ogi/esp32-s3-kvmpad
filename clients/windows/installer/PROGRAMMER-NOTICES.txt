KVMpad Windows programmer notices

KVMpad CLIENT runs esptool as a separate command-line program. This release
includes the unmodified esptool 5.6.0 package from Fredrik Ahlberg,
Angus Gratton and Espressif Systems, under GPL-2.0-or-later. The same
package provides espefuse and espsecure. The full GPL version 2 is in
runtime/Lib/site-packages/esptool-5.6.0.dist-info/licenses/LICENSE.

The esptool package contains two sets of compiled flasher stubs.
The legacy stubs are esptool-legacy-flasher-stub v1.11.1 under
GPL-2.0-or-later. The current stubs are esp-flasher-stub v1.4.1 with
esp-stub-lib at 26e5798f1d9ab335072fa87102ec3314f87024a7, under
Apache-2.0 OR MIT. Their license texts are in
runtime/Lib/site-packages/esptool/targets/stub_flasher/2/.

The complete programmer source package is kvmpad-programmer-source.zip
beside this installer on the KVMpad release page.
https://github.com/D-Ogi/esp32-s3-kvmpad/releases

Upstream releases:
